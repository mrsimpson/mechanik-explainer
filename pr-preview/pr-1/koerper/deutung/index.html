Warum

Wer misst, schreibt auf, was er sieht und abliest. Danach überlegt er, warum es so ist. Beides gehört zusammen, darf aber nicht vermischt werden. Sonst hält man seine Vermutung für ein Ergebnis.

Regel

Beobachtung

Eine Beobachtung hält fest, was du siehst oder abliest, ohne Erklärung.

Deutung

Eine Deutung erklärt, warum etwas so ist. Sie ist eine Vermutung, die du prüfen kannst.

Merkhilfe

Steht im Satz ein "weil", ist es meist eine Deutung.

Übung

Übung

Der Satz "Die Waage zeigt 300 g an." ist eine Beobachtung.

Richtige Antwort: Die Aussage stimmt.

Der Satz hält nur fest, was an der Waage abzulesen ist. Eine Erklärung steht nicht darin.

Übung

Der Satz "Der Stein ist schwer, weil er aus Eisen besteht." ist eine Beobachtung.

Richtige Antwort: Die Aussage stimmt nicht.

Der Satz erklärt, warum der Stein schwer ist. Das ist eine Deutung. Die Beobachtung wäre nur "Der Stein ist schwer."
